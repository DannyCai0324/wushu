# atlas / arm-inner — 上肢屈側（陰面）

第一張面板。手太陰肺經 LU3–11、手少陰心經 HT1–9、手厥陰心包經 PC2–9，共 **26 穴**。

## 交付檔案

| 檔案 | 大小 | 說明 |
|---|---|---|
| `arm-inner.js` | 約 17 KB | **唯一真實來源**。面板幾何、26 穴資料、`loc` 文字、渲染函式。無外部相依、不使用任何瀏覽器儲存 API |
| `arm-inner.svg` | 約 22 KB | 靜態成品，瀏覽器可直接開。**由 `arm-inner.js` 跑出來再存檔**，不是手寫的，所以兩者不會漂移 |

| `_mobile-test.html` | 2.5 KB | 390px 驗收用的示範宿主頁。**不是交付物**，但裡面的容器 CSS 就是合併時該用的那一份 |

## 這一版的三個決定

### 1. 視角改成「自身視角」（使用者要求）

**手在上、手指朝上、肩在下。橈側（拇指側）在畫面右，尺側（小指側）在畫面左。**

理由是實際取穴時，人是舉起自己的前臂在看，圖跟眼睛看到的一致才不用在腦中翻轉。

⚠ 這與常見的「他人正面觀」剛好差 **180° 旋轉**——上下與左右**都要**相反。
（我第一版只翻上下、沒翻左右，被使用者抓到：右前臂掌心朝上時拇指在右，不是在左。）

### 2. 手部加了兩層標誌（不只是輪廓）

上一版被打回來的原因是「點浮在人形上」。手部密度最高，所以除了輪廓另外畫了：

- **掌骨 1–5**（虛線）——`loc` 裡大量出現「第2、3掌骨之間」「第4、5掌骨之間」「第1掌骨中點橈側」，沒有掌骨就對不上
- **赤白肉際**（金色點線）——井滎輸原一整組的定位基準（LU10 魚際、LI2、LI3、SI2、SI3、SP2、SP3…）
- **掌指關節**橫線

右側有小圖例標示這兩條線各是什麼。

### 3. 各段的 px/寸 不同，這是正確的

腕→肘 12 寸用 340px、肘→腋 9 寸用 190px。骨度分寸本來就是**各段各自折量**，全身用同一個比例反而會錯。

## 合併需要的東西（給雲端那端）

1. `<script src>` 或直接內嵌 `arm-inner.js`，然後：
   ```js
   ARM_INNER.render(container, {mer:"ALL", sel:null}, function(code, info){ /* 顯示 info */ });
   ```
   `info` = `{name, code, meridian, loc}`。
2. 容器 CSS **必須**有 `overflow-x:auto; max-width:100%`，SVG 保持自然寬度不要縮放——縮小後穴名會小到看不清。完整可用的容器樣式見 `_mobile-test.html`。
3. 經脈切換與點擊詳情屬於宿主頁的職責，`arm-inner.js` 只負責畫圖與回呼。

## 已知不夠好的地方

1. **手掌與手指是示意圖**，四指用圓角矩形、拇指用曲線，談不上精緻。已改過三輪（原本方塊感很重、中間試過單一輪廓反而讓小指跟掌緣糊在一起）。
   末端穴本來就吃解剖標誌不吃骨度分寸，畫得再精緻精度也不會變好，改善的是好不好認。
   **建議等 `arm-outer` 做完，手的正反面一起定版**；腳的三張同理，一次解決四張比較划算。
2. **HT1 極泉超出 0–21 寸刻度**，只能手動定位。
3. **腕橫紋的標誌名壓在手掌下緣上**，讀得到但疊在圖上。左側穴名欄已經滿了，要再挪就得加寬 viewBox。
4. 前臂／上臂輪廓已改成曲線，但仍偏簡單。
