# 2026-08-07 ｜標註排版修正

## 這一輪只改排版，沒有動任何座標

上一版被指出的問題：左右標籤等間距排列、穴點卻照真實寸數擺放，腕部 0/0.5/1/1.5/2/3 寸
六個穴擠在 85px 內，標籤被推開、牽引線變成長斜線並互相交叉，
**標籤與穴點的最大垂直落差約 100px（約 3.5 寸）**。

### 座標未更動的證明

`axis` / `edges` / `lanes` / `pts` 四塊資料與 `afba11d` 版**逐字比對，34 行全部相同**：

```
$ git show afba11d:atlas/arm-inner.js | grep -E 'cun: [0-9]|{ y: [0-9]+, l: |lanes: {|code: "'  > before
$ grep -E 'cun: [0-9]|{ y: [0-9]+, l: |lanes: {|code: "' atlas/arm-inner.js > after
$ diff before after
（只有一行註解文字由「在腋前紋頭之下」改為「之外」，座標 x:224, y:838 完全相同）
```

座標是由這四塊資料內插算出來的，資料一致即座標一致。
另在瀏覽器內以 `ARM_INNER.audit().coords` 取回 26 筆實際座標覆核，
與規格書引用的數值相符：太淵 LU9／大陵 PC7／神門 HT7 皆為 y=300；內關 PC6 y=356.67；
尺澤 LU5、曲澤 PC3 y=640；天府 LU3 y=766.67。

## 改了什麼

1. **牽引線改直角折線**（`leaderPath()`）
   穴點 → 水平短線 → 轉垂直走專屬導引槽 → 再轉水平接標籤。沒有任何單一斜線。
2. **雙子欄**（`layoutSide()`）
   每側的標籤交錯分配到近欄／遠欄，同欄相鄰間距 19px，垂直推擠量直接減半。
3. **位移上限 40px**（`MAX_SHIFT`）
   超過就把該標籤換到另一個子欄重排，不再往垂直方向推。
4. **導引槽邊緣刻痕**
   每個穴點的**真實 y** 在槽緣畫 4px 短橫線，用該經顏色。標籤被推開時仍看得到實際高度。
5. **牽引線用所屬經脈顏色**，起點座標即穴點圓心（浮點完全相同）。
6. **標誌名加底色塊**（`markLabel()`）
   腕橫紋、掌指關節、肘橫紋、腋前紋頭四個名稱都加 `#1d1730` 底塊，不再被圖形或牽引線蓋住。
7. **HT1 極泉軸外註記**
   極泉在腋窩中央、y=838，超出 0–21 寸刻度（腋前紋頭 y=830）。
   保留原座標，標籤下方加註「軸外・腋窩中央」，不假造刻度。
8. **viewBox 由 `0 0 620 900` 改為 `-150 0 770 900`**
   只是把畫布往左讓出標籤空間，**所有穴位座標不受影響**（x 起點為負而已）。

### 不交叉是怎麼保證的（三個關鍵，缺一就會冒出交叉）

改的過程中交叉數是 9 → 5 → 1 → 1 → **0**，每一步都由程式檢查，不是目視：

- **導引槽依「最終標籤 y」排序配置，不是依穴點 y。**
  標籤推擠後兩者順序會不一致，一不一致就交叉。
- **同一列（y 差 < 6px）內，內側的穴排前面**，讓它拿到最外側的導引槽。
  只用 y 排序不夠——HT8 與 PC8 只差 2px，不算同 y 卻已互相干擾，所以先分列再排。
- **同列內側那條起步的小垂直段（jog）方向由程式選**，必須同時滿足：
  ① 它的水平短線不落在任何內側槽的垂直段範圍內
  ② 它自己的垂直段不蓋住任何外側那條的水平短線
  寫死方向會失敗：往上抖蓋住 HT8，往下抖又撞進 HT3。

## 視角與手部標誌（上一輪定案，未變）

**自身視角**：手在上、手指朝上、橈側在畫面右、尺側在畫面左。
與「他人正面觀」差 **180° 旋轉**，上下與左右都相反。

手部除輪廓外另有兩層標誌，因為 `loc` 直接引用它們：
- **掌骨 1–5**（虛線）——「第2、3掌骨之間」「第1掌骨中點橈側」
- **赤白肉際**（金色點線）——井滎輸原一整組的基準
- **掌指關節**橫線

## 合併需要的東西（給雲端那端）

```js
ARM_INNER.render(container, { mer: "ALL", sel: null }, function (code, info) { /* 顯示 info */ });
// info = { name, code, meridian, loc }
```
容器 CSS **必須**有 `overflow-x:auto; max-width:100%`，SVG 保持自然寬度 770 不要縮放。
完整可用的樣式見 `_mobile-test.html`。經脈切換與點擊詳情屬於宿主頁職責。
